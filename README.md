# Welding_Gun_Repair_Tracker
### Description
Project to track repairs of welding guns in a fitting and turning workplace. Built for a client in 2024 as a highschool VCE Software Development Project. This involved developing a program with a client, getting requirements, building a gantt chart, writing a software requirements specification document, developing, testing, and writing a requirement evaluation document.
<br>
### Installation
- Download WeldingGunTracker folder and WeldinGunTracker.sln
- Open .sln with Visual Studio 2022
- Compile and run
<br>
### Usage
- Repairs can be added, and may consist of a welding gun, repairer, parts, problems, and fixes. All of these may be recorded when a repair is added.
- Welding guns may also be added with their date, and state.
- Repairs and guns are listed on the screen in a table, where users can filter, search and order them.
- Settings can be assed to change basic options as well as dropdown values for more efficient use
